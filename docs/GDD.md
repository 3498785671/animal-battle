# 《动物大逃杀》游戏设计文档（GDD）

> 版本 v1.0.0 ｜ 平台：Android（原生 Kotlin）｜ 类型：单机割草 / 幸存者-like

---

## 1. 概述

《动物大逃杀》是一款面向安卓手机玩家的**单机割草类**游戏。玩家控制一只狐狸，在封闭地图中对抗成群刷新的敌人（狼、熊、野猪、毒蛇等），通过自动攻击与主动技能不断击杀、升级变强，追求"满屏特效、高频率击杀"的极致爽感。游戏可完全离线运行。

**核心体验**：爽快割草 —— 简单上手、自动攻击、华丽特效、越战越强的成长反馈。

**目标受众**：安卓手机玩家，追求碎片时间消遣与解压爽感；兼容中低端设备流畅运行。

---

## 2. 核心玩法循环

```
移动（虚拟摇杆） → 自动攻击敌人 → 击杀掉落经验球 → 拾取升级 → 三选一强化 → 变强杀更多
                              ↘ 金币/血包掉落
血量归零 → 结算（击杀数/生存时间/金币） → 金币用于局外养成 → 再开一局
```

**单局目标**：无尽生存，尽可能存活更久、击杀更多，刷新最高分。

---

## 3. 核心系统

### 3.1 移动与操作
- **虚拟摇杆**（屏幕左下）：控制狐狸移动，支持多点触控。
- **自动普攻**：狐狸自动锁定最近的敌人并发射弹幕。
- **3 个主动技能按钮**（屏幕右下）：手动释放大招。

### 3.2 战斗系统
- 子弹与敌人使用**空间网格**做近邻碰撞检测，命中即扣血、轻微击退。
- 敌人碰触玩家造成伤害，玩家有短暂受击无敌与受击闪烁。
- 精英/Boss 死亡触发屏幕震动，强化打击感。

### 3.3 敌人设计
| 敌人 | 特点 | 解锁时间 |
|---|---|---|
| 狼 | 快、脆、数量多 | 开局 |
| 野猪 | 会冲锋，中速 | 30s |
| 毒蛇 | 命中玩家减速 | 70s |
| 熊 | 慢、血量厚、伤害高 | 120s |
| 刺猬 | 慢、伤害高 | 150s |
| 精英 | 大体积、高血量 | 180s（低概率） |
| 蝙蝠 | 快、飞行摆动 | 210s |
| Boss | 每 90 秒一只，超大血量 | 90s |

- 敌人成群从地图边缘刷入，刷怪间隔与强度随生存时间递增（数值在 `GameConfig.kt` 可调）。

### 3.4 升级三选一（局内）
升级时弹出三选一，随机抽取 3 项不同的强化：
攻击力 +20% ／ 攻速 +15% ／ 弹幕 +1 ／ 移速 +12% ／ 最大生命 +25 ／ 护甲 +10% ／ 拾取范围 +40% ／ 嗜血（击杀回血）／ 技能冷却 -15% ／ 急救 ／ 穿甲弹（穿透 +1）／ 爆裂弹（命中范围爆炸）／ 致命一击（暴击率 +15%）／ 聚宝盆（金币 +25%）。

### 3.5 主动技能
| 技能 | 效果 | 冷却 |
|---|---|---|
| 狐火爆裂 | 对全屏敌人造成大量伤害 + 震屏 | 12s |
| 疾风冲刺 | 向移动方向冲刺，期间无敌 + 路径伤害 | 6s |
| 灵狐召唤 | 召唤环绕灵狐自动射击（最多 4 只） | 16s |

### 3.6 局外养成
- **金币**：击杀掉落 + 局末结算奖励。
- **永久属性**（5 项，逐级涨价）：攻击、最大生命、移速、经验获取、金币获取。
- **角色解锁**：狐狸（默认）、兔子（移速+15%）、熊猫（生命+40%）、灰狼（攻击+30%），各有被动加成。

### 3.7 结算与高分榜
局末展示存活时间、击杀数、获得金币、历史最高击杀；记录最高击杀 / 最高存活时间 / 历史金币。

## 4. 视觉风格

- **卡通可爱、色彩鲜明**：明亮草地绿背景、浅色网格、几何卡通角色（圆身体 + 耳朵 + 大眼睛）。
- **华丽特效**：击杀爆炸粒子、命中闪光、屏幕震动、经验/金币光点、技能全屏特效。
- **角色均为程序绘制**（Canvas 几何绘制），可无缝替换为 PNG 素材。

---

## 5. 技术架构

- **语言/引擎**：Kotlin + 原生 Android（无第三方依赖、无游戏引擎）。
- **渲染**：`SurfaceView` + `Canvas` 自绘，独立渲染线程，固定时间步长（60 FPS）。
- **架构分层**：
  - `engine/`：对象池、空间网格、游戏循环。
  - `entity/`：玩家、敌人、子弹、掉落物、粒子（数据类）。
  - `system/`（逻辑集中在 `GameState`）：生成、碰撞、战斗、升级、技能。
  - `render/`：全部 Canvas 绘制。
  - `ui/`：虚拟摇杆、按钮模型。
  - `data/`：数值配置、本地存档。

---

## 6. 性能优化（中低端机目标）

1. **对象池**：敌人/子弹/掉落物/粒子全部复用，避免频繁 GC。
2. **空间网格**：子弹-敌人碰撞 O(1) 近邻查询，替代全量遍历。
3. **粒子数量上限**（380），超限自动丢弃。
4. **固定时间步长** + 单帧最长步进限制，卡顿时不会雪崩。
5. **渲染复用 Paint**，避免循环内分配对象；逻辑坐标统一缩放。

## 7. 资源清单

| 资源 | 现状 | 替换方式 |
|---|---|---|
| 玩家/敌人形象 | 程序绘制几何卡通 | 在 `Renderer.kt` 的绘制函数替换为 `drawBitmap` |
| 特效 | 程序粒子 | 同上，或替换为帧动画 |
| 图标 | `scripts/gen_icon.py` 生成 PNG | 重新生成或替换 `res/mipmap-*` |
| 音效/音乐 | 暂无（后续可加 `SoundPool`） | 放入 `res/raw` 并播放 |
| 存档 | `SharedPreferences` | 如需云存档可替换 |

## 8. 目录结构

```
动物大逃杀/
├── app/src/main/java/com/animal/battle/
│   ├── MainActivity.kt        # 入口（全屏沉浸竖屏）
│   ├── GameView.kt            # SurfaceView + 游戏循环 + 状态机 + 触摸
│   ├── GameState.kt           # 游戏世界核心模拟
│   ├── engine/                # ObjectPool / SpatialGrid
│   ├── entity/                # Player / Enemy / Bullet / Pickup / Particle
│   ├── render/Renderer.kt     # 全部 Canvas 绘制
│   ├── ui/                    # Joystick / UIButton
│   └── data/                  # GameConfig / SaveManager
├── app/src/main/res/          # 图标、字符串
├── scripts/gen_icon.py        # 图标生成脚本
├── docs/                      # 本文档 + 打包发布指南
└── gradle/ + local.properties
```
